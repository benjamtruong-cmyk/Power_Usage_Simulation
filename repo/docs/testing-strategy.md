## How we tested

### Unit-level checks

For each class, we verified individual methods before integrating:

- **Appliance.determineOnOff():** Ran 10,000 calls with `probOn = 0.5`, counted ON results. Got ~50% — confirms the random distribution is working.
- **SmartAppliance.getLowPower():** Checked with known values: 1200W at 25% reduction → 900W. 5400W at 33% reduction → 3618W.
- **SmartAppliance.getSavings():** Verified it returns `onWattage - getLowPower()` correctly for several test cases.
- **Location.brownOut():** Created a location with 3 appliances (ON/LOW/ON), called brownOut(), verified all became OFF and returned the correct total freed wattage.
- **PowerGrid.readAppFile():** Fed it files with valid lines, blank lines, malformed lines, and invalid ranges. Confirmed it loads good lines and skips bad ones with warnings.

### Integration tests

After connecting everything, we tested full simulation runs:

1. Loaded `app.txt` (the provided sample file), set warning to 5000W, ran 20 timesteps. Verified per-timestep output appeared, summary printed, and `simulation_report.txt` was generated with correct data.
2. Generated a large file using `ApplianceGenerator.java`, loaded 1740+ appliances, ran 50 timesteps. Program handled it without errors or noticeable slowdown.
3. Tested the menu: A (add), L (list to verify), D (delete), L (verify deleted), F (load file), L (verify loaded), S (simulate).

### Edge cases we specifically checked

- **All appliances OFF:** Set probOn = 0.0 for everything. No algorithm activation needed — program handles it gracefully.
- **Warning level = 1:** Extremely low threshold forces both phases to activate every timestep.
- **Single appliance:** Just one smart appliance in one location. Confirmed throttling works on a single device.
- **Duplicate location IDs in CSV:** Multiple lines with the same locationID correctly group into one Location object.

## Files used for testing

- `data/app.txt` — the sample file provided with the assignment (30 appliances across several locations)
- Files generated by `data/ApplianceGenerator.java` — larger test sets with randomized data
- Manually crafted edge-case files for specific scenarios listed above
